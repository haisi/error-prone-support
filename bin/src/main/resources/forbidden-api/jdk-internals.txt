# jdk-internals: obvious internal/undocumented JDK namespaces.
#
# Caveats:
# - sun.**: always internal, unsupported, and not part of any specified API - safe to forbid
#   unconditionally.
# - jdk.internal.**: same as sun.** - internal implementation detail of the JDK itself, not
#   exported to application code (JPMS blocks it outright on the module path).
# - com.sun.**: this one is NOT uniformly internal. Several artifacts under com.sun.* are, in
#   fact, standardized/public API that merely kept its legacy package name - most notably
#   com.sun.net.httpserver (the JDK's built-in HTTP server API) and com.sun.security.auth /
#   com.sun.security.jgss. Banning all of com.sun.** as a blanket rule is a portability and
#   false-positive risk; consumers who need those specific supported subpackages should carve out
#   an exception (forbidden-apis has no "unforbid" syntax here - simply don't enable this bundle,
#   or maintain a local copy of this file without the com.sun.** line, in that case).
